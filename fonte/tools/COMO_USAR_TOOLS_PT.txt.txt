================================================================================
                  CONTEÚDO NECESSÁRIO DENTRO DA PASTA 'tools'
================================================================================

Para garantir o funcionamento correto do LaFirma Remux Forge, a pasta "tools\" 
deve conter estritamente os seguintes executáveis, bibliotecas e subpastAS:

1. ARQUIVOS NA RAIZ (tools\)
--------------------------------------------------------------------------------
   - ffmpeg.exe        : Ferramenta principal de processamento de mídia
   - ffprobe.exe       : Analisador de faixas e fluxos de mídia
   - dovi_tool.exe     : Utilitário para manipulação de Dolby Vision RPU
   - mkvmerge.exe      : Multiplexador de arquivos Matroska (.mkv)
   - mkvextract.exe    : Extrator de faixas de arquivos .mkv
   - MediaInfo.exe     : Leitor detalhado de metadados
   - LIBCURL.DLL       : Biblioteca para requisições de rede
   - nvcuda.dll        : Biblioteca de aceleração NVIDIA CUDA
   - nvcuvid.dll       : Biblioteca do NVIDIA Video Codec SDK

2. SUBPASTAS OBRIGATÓRIAS (tools\)
--------------------------------------------------------------------------------
   - SubtitleEdit\
       |-- seconv.exe         : Executável principal para o OCR preferencial
       |-- Latin.db           : Banco de dados de caracteres ópticos
       |-- libSkiaSharp.dll   : Biblioteca gráfica (obrigatória para o seconv)

   - PgsToSrt\
       |-- PgsToSrt.exe       : Utilitário de OCR reserva (rede de segurança)
       |-- x64\               : Binários de arquitetura
       |-- tessdata\          : Modelo de linguagem do Tesseract
             |-- por.traineddata

   - Tesseract\
       |-- tesseract.exe      : Motor de Re-OCR para falas curtas
       |-- tessdata\          : Arquivos de treinamento de linguagem
             |-- por.traineddata
             |-- osd.traineddata

   - DeeZy\
       |-- deezy.exe          : Utilitário para conversão TrueHD/Atmos -> E-AC-3
       |-- apps\              : Motores internos de áudio (dee, truehdd)
       |-- bundle\            : Módulos e dependências de suporte
================================================================================
