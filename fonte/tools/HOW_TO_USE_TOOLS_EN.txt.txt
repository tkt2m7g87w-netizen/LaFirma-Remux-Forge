================================================================================
                     REQUIRED CONTENTS OF THE 'tools' FOLDER
================================================================================

To ensure that LaFirma Remux Forge functions correctly, the "tools\" directory 
must contain the following binaries, libraries, and subdirectories:

1. ROOT DIRECTORY (tools\)
--------------------------------------------------------------------------------
   - ffmpeg.exe        : Core media processing tool
   - ffprobe.exe       : Media stream analysis tool
   - dovi_tool.exe     : Dolby Vision RPU manipulation utility
   - mkvmerge.exe      : Matroska multiplexer
   - mkvextract.exe    : Matroska track extractor
   - MediaInfo.exe     : Detailed media inspector
   - LIBCURL.DLL       : Networking/HTTP library
   - nvcuda.dll        : NVIDIA CUDA acceleration library
   - nvcuvid.dll       : NVIDIA Video Codec SDK library

2. REQUIRED SUBDIRECTORIES (tools\)
--------------------------------------------------------------------------------
   - SubtitleEdit\
       |-- seconv.exe         : Preferred OCR processing binary
       |-- Latin.db           : Optical character database
       |-- libSkiaSharp.dll   : Graphics engine dependency

   - PgsToSrt\
       |-- PgsToSrt.exe       : Secondary fallback OCR utility
       |-- x64\               : Architecture binaries
       |-- tessdata\          : Tesseract language model data
             |-- por.traineddata

   - Tesseract\
       |-- tesseract.exe      : Standalone engine for short-line re-OCR
       |-- tessdata\          : Language and layout models
             |-- por.traineddata
             |-- osd.traineddata

   - DeeZy\
       |-- deezy.exe          : Audio processing CLI wrapper
       |-- apps\              : Internal engine dependencies (dee, truehdd)
       |-- bundle\            : Supporting libraries/executables
================================================================================
