================================================================================
          LaFirma Remux Forge - WHAT GOES IN THE 'tools' FOLDER
================================================================================

The "tools\" folder sits next to LaFirma_JANELA.ps1 and must contain EXACTLY
what is listed below. The installer already ships all of it. This text is for
anyone who wants to build the folder by hand.

Ready-made folder:

  tools.rar    - Proton: https://drive.proton.me/urls/REAQGVN7D4#RXvf7kjVeJ1I
  folder       - MEGA  : https://mega.nz/folder/HbwiFAab#4-tWrGlGfoEN0xRopn_8IQ
  folder       - Proton: https://drive.proton.me/urls/5Y8AZ9QZ6C#YnOKpcuVRXUk

1. FILES IN THE ROOT (tools\)
--------------------------------------------------------------------------------
   - ffmpeg.exe      : extracts the video from the MKV and checks the output
   - ffprobe.exe     : reads tracks, duration and FPS
   - dovi_tool.exe   : converts Dolby Vision (Profile 7 -> 8.1) and measures
                       the enhancement layer (MEL x FEL). Version 2.3.3.
   - mkvmerge.exe    : reads tracks and builds the final MKV
   - MediaInfo.exe   : detects Atmos/JOC in the audio tracks

2. SUBFOLDERS
--------------------------------------------------------------------------------
   - PgsToSrt\        PGS subtitle OCR -> .SRT
       |-- PgsToSrt.exe
       |-- x64\                   (Tesseract libraries it uses)
       |-- tessdata\
             |-- por.traineddata

   - Tesseract\       re-OCR of short lines (fixes "INF TOL" -> "Não!")
       |-- tesseract.exe          (+ the DLLs that ship with it)
       |-- tessdata\
             |-- por.traineddata

   - DeeZy\           TrueHD/Atmos -> E-AC-3 Atmos
       |-- deezy.exe
       |-- apps\dee\dee.exe
       |-- apps\truehdd\truehdd.exe
       |-- (the other files that ship with DeeZy)
       DeeZy uses the ffmpeg.exe in the root of tools\ - the copy in
       apps\ffmpeg\ is not needed.

3. NO LONGER NEEDED
--------------------------------------------------------------------------------
   - SubtitleEdit\ (seconv, Latin.db, libSkiaSharp.dll): removed in 2.0.
     OCR is now PgsToSrt + Tesseract only.
   - mkvextract.exe, LIBCURL.DLL, nvcuda.dll, nvcuvid.dll: not used.
   - PgsToSrt\x86\: only x64 is used.

4. OUTSIDE THE tools FOLDER
--------------------------------------------------------------------------------
   - .NET Desktop Runtime 8 (x64): required by PgsToSrt. The installer adds it
     if missing; when building by hand, install it yourself:
     https://dotnet.microsoft.com/download/dotnet/8.0
