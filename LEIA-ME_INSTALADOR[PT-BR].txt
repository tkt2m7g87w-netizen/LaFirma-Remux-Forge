================================================================================
           GUIA DE COMPILAÇÃO E INSTALAÇÃO COM INNO SETUP (.ISS)
                      LaFirma Remux Forge - Black Edition
================================================================================

ESTE GUIA É PARA DESENVOLVEDORES / CRIADORES DE BUILD.
Se você é o usuário final, apenas execute o arquivo 'LaFirma_Setup.exe'.

--------------------------------------------------------------------------------
1. VISÃO GERAL E FILOSOFIA DE REPOSITÓRIO (GITHUB)
--------------------------------------------------------------------------------
Por questões de direitos autorais e limites de tamanho de repositório, os
arquivos binários pesados e ferramentas de terceiros contidos na pasta 'tools\'
NÃO PODEM SER ENVIADOS AO GITHUB.

O repositório contém apenas os scripts fontes (.ps1, .bat, .vbs), arquivos de
configuração, dicionários e este script do Inno Setup (.iss).

Para compilar o instalador (.exe) a partir do código raiz, VOCÊ DEVE OBTER
AS FERRAMENTAS MANUALMENTE E MONTAR A PASTA 'tools\' antes de executar a
compilação do arquivo .iss.


--------------------------------------------------------------------------------
2. REQUISITOS PRÉVIOS PARA COMPILAR
--------------------------------------------------------------------------------
1. Inno Setup 6 (ou superior) instalado no Windows.
   - Download oficial: https://jrsoftware.org/isdl.php
2. (Opcional, mas recomendado) Dependência .NET na pasta redist\:
   - Baixe o instalador do "Windows Desktop Runtime 8.0.30 (x64)" da Microsoft.
   - Link oficial: https://dotnet.microsoft.com/download/dotnet/8.0
   - Coloque o instalador .exe dentro da pasta 'redist\'.
   - Nota: Se a pasta 'redist\' estiver vazia, o Inno Setup gerará o instalador
     normalmente (58 MB menor), mas o instalador tentará baixar o .NET da 
     web caso a máquina de destino não o possua.


--------------------------------------------------------------------------------
3. ONDE OBTER CADA FERRAMENTA DA PASTA 'tools\'
--------------------------------------------------------------------------------
Baixe os pacotes compactados dos links abaixo e extraia os executáveis/pastas
diretamente na estrutura da pasta 'tools\':

1. FFmpeg e FFprobe (ffmpeg.exe, ffprobe.exe):
   - Fonte: Releases do Gyan.dev ou BtbN no GitHub.
   - Link: https://www.gyan.dev/ffmpeg/builds/ (Baixe a versão 'ffmpeg-git-full.7z')
   - Ação: Copie 'ffmpeg.exe' e 'ffprobe.exe' da pasta 'bin' para a raiz de 'tools\'.

2. dovi_tool (dovi_tool.exe):
   - Fonte: Repositório quietvoid/dovi_tool no GitHub.
   - Link: https://github.com/quietvoid/dovi_tool/releases
   - Ação: Baixe o arquivo 'dovi_tool-x.x.x-x86_64-pc-windows-msvc.zip', extraia e
     coloque o 'dovi_tool.exe' na raiz de 'tools\'.

3. MKVToolNix (mkvmerge.exe, mkvextract.exe):
   - Fonte: Download oficial do MKVToolNix.
   - Link: https://mkvtoolnix.download/downloads.html#windows
   - Ação: Baixe a versão 'portable' (.7z ou .zip), extraia e copie 'mkvmerge.exe' e 
     'mkvextract.exe' para a raiz de 'tools\'.

4. MediaInfo CLI (MediaInfo.exe, DLLs nvcuda/nvcuvid/LIBCURL):
   - Fonte: Download oficial do MediaInfo (CLI release).
   - Link: https://mediaarea.net/en/MediaInfo/Download/Windows
   - Ação: Baixe a versão "Command Line Interface (CLI)" de 64-bit e extraia o 
     'MediaInfo.exe' e suas DLLs auxiliares para a raiz de 'tools\'.

5. SubtitleEdit (Subpasta SubtitleEdit\):
   - Fonte: Repositório SubtitleEdit no GitHub.
   - Link: https://github.com/SubtitleEdit/subtitleedit/releases
   - Ação: Baixe o pacote portátil 'SE3xx.zip' e extraia seus arquivos dentro de 
     'tools\SubtitleEdit\'. 
     *IMPORTANTE*: Certifique-se de que a biblioteca 'libSkiaSharp.dll' e o arquivo 
     'Latin.db' estão presentes nessa subpasta junto ao 'seconv.exe'.

6. PgsToSrt (Subpasta PgsToSrt\):
   - Fonte: Repositório PgsToSrt no GitHub.
   - Link: https://github.com/Tensai75/PgsToSrt/releases
   - Ação: Extraia a release portátil em 'tools\PgsToSrt\'. Garanta que a subpasta
     'tessdata\' contenha o arquivo 'por.traineddata' (treinamento em Português).

7. Tesseract OCR (Subpasta Tesseract\):
   - Fonte: Repositório tesseract-ocr/tesseract ou binaries do UB-Mannheim.
   - Link: https://github.com/UB-Mannheim/tesseract/wiki
   - Ação: Instale/Extraia os arquivos em 'tools\Tesseract\', certificando-se de 
     que 'tesseract.exe' esteja presente e que dentro de 'tools\Tesseract\tessdata\' 
     estejam os arquivos 'por.traineddata' e 'osd.traineddata'.

8. DeeZy (Subpasta DeeZy\):
   - Fonte: Repositório JessieLW/DeeZy no GitHub.
   - Link: https://jessielw.github.io/DeeZy/ ou https://github.com/JessieLW/DeeZy
   - Ação: Extraia o executável 'deezy.exe' e a pasta 'apps\' em 'tools\DeeZy\'.

5. PASSO A PASSO PARA GERAR O INSTALADOR (.ISS)
--------------------------------------------------------------------------------
1. Certifique-se de ter baixado e posicionado todas as ferramentas da Seção 3 
   na pasta 'tools\'.

2. Abra o software Inno Setup Compiler no seu Windows.

3. Clique em "File" -> "Open..." e selecione o arquivo 'LaFirma_Setup.iss'.

4. Clique no menu "Build" -> "Compile" (ou pressione o atalho Ctrl + F9).

5. O Inno Setup lerá os scripts da raiz, empacotará os executáveis da pasta 
   'tools\', incluirá as dependências do 'redist\' (se existirem) e criará 
   o arquivo instalador final dentro da pasta 'Output\' (ex: Output\LaFirma_Setup.exe).

6. Pronto! O 'LaFirma_Setup.exe' resultante já estará pronto para ser distribuído. 
   Quando o usuário final executá-lo, o Inno Setup criará a estrutura completa 
   no computador dele de forma automatizada, sem que ele precise baixar nada 
   da pasta 'tools\' manualmente.
